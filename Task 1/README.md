# Personal Introduction Program

## 1. Project Overview

This is a simple Python program that asks users about themselves and generates a personalized introduction.

**Objectives:**

- Learn how to take user input.
- Understand variables and data types.
- Practice using f-strings.
- Display dynamic output.

## 2. Setup Instructions

**Requirements:** Python 3.x

**Steps to run:**

1. Install Python from https://www.python.org/
2. Download the project.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python personal_intro.py
```

5. Answer the questions displayed on the screen.

No external libraries are required.

## 5. Technical Details

The project uses basic Python concepts:

- `input()` – Takes information from the user.
- Variables – Store user responses.
- `int()` – Converts age into an integer.
- `print()` – Displays output.
- f-strings – Insert variables into sentences.

The program follows a simple sequence: Input → Processing → Output.

## 7. Conclusion

This project helped demonstrate basic Python concepts such as user input, variables, data type conversion, and string formatting through a simple interactive application.
